# InsightLab — Skill Bridge Project Website

A responsive, single-page project website that embeds the published Tableau dashboard and story.

## Files
- `index.html` — complete website (HTML, CSS, and Tableau embed)

## Run locally
1. Extract the ZIP.
2. Open the `skill_bridge_website` folder.
3. Double-click `index.html` to open it in a browser.
   - Recommended: use VS Code and the Live Server extension for a local preview.

An internet connection is required for Google Fonts and Tableau embeds.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the deployment and open the URL shown in the Pages section.

## Important
The website links to and embeds the Tableau Public views supplied for this project. If the embedded visualizations do not load, confirm that the workbook is still public and use the “Open in Tableau” buttons. Tableau Public workbooks are publicly accessible.
